DefenderPilot — управление Microsoft Defender для Windows 10/11 x64.

- Включение защиты и восстановление основных параметров.
- Временное отключение защиты в реальном времени с проверкой результата.
- Восстановление компонентов Windows через DISM и SFC.
- Обновление антивирусных баз, состояние службы и защита от подделки.
- Русский интерфейс, журнал операций, запуск с правами администратора.

Скачайте **DefenderPilot.exe**. Устанавливать Python не требуется.

Отключение временное: Windows может включить защиту снова. Защита от подделки и политики организации могут запрещать изменения. Полностью удалённые компоненты Defender могут потребовать восстановительной установки Windows с сохранением файлов.
